Dán mã sản phẩm, mỗi mã một dòng. App tìm trong kho Google Sheets / dữ liệu đã tải; mã chưa có sẽ được báo riêng, không tự ý tạo hoặc xóa dữ liệu.

Chưa chọn sản phẩm.

Kho dữ liệu

Đồng bộ lên Sheet gửi toàn bộ kho qua Apps Script action syncProducts. Nếu Apps Script ghi thay thế toàn bộ sheet, hãy tải Sheet và kiểm tra cảnh báo trước khi ghi. Không bấm lưu khi danh sách đang thiếu sản phẩm.
Chưa tải dữ liệu từ Sheet.
MãTên sản phẩmGiá

Kết nối đi qua API proxy của server hiện tại, không gọi trực tiếp Apps Script từ trình duyệt. Mã server hỗ trợ GET action=getProducts và POST action=syncProducts. Việc cập nhật thực tế phụ thuộc vào mã Apps Script đang triển khai.

Sao lưu nhanh được lưu tại trình duyệt này; hãy tải file JSON định kỳ để có bản backup ngoài trình duyệt. Nhật ký người sửa chỉ đáng tin cậy khi Apps Script lưu log phía máy chủ.
